## 🎮 Visão da Gamificação

### Conceito

Transformar o Kanban em um escritório virtual onde:

- **Tarefas** = Personagens pixel art
- **Status** = Locais do escritório
- **Ações** = Animações e movimentos

### Áreas do Escritório

| Status      | Nome Visual      | Emoji |
| ----------- | ---------------- | ----- |
| todo        | Sala de Espera   | 🪑    |
| in-progress | Área de Trabalho | 💻    |
| blocked     | Zona Bloqueada   | 🚧    |
| done        | Área de Sucesso  | 🎉    |

### Stack

- **Phaser.js** - Motor de jogos 2D
- **React** - Integração com UI
- **TypeScript** - Tipagem
